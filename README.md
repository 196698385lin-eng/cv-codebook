# 机器视觉常用代码字典

一份可以直接抄用的 OpenCV / PyTorch 模板集，共 31 个模板，覆盖从读图到机械臂执行的完整链路。

每个模板都标出了需要改动的位置（图片路径、颜色阈值、保存文件名），把路径换掉就能跑。

## 阅读方式

- 在线版本：[codebook.md](codebook.md)，GitHub 上直接渲染，带目录和代码高亮
- 原始文档：[常用代码字典.docx](常用代码字典.docx)

## 组织方式

字典按数据流分成八组，前一组是后一组的输入。

| 组 | 内容 | 模板 |
| --- | --- | --- |
| 第一组 | 读图和基础变换 | 1–3 |
| 第二组 | 找轮廓、画框、量面积 | 4–7 |
| 第三组 | 判断形状、过滤噪点、自己造测试图 | 8–10 |
| 第四组 | 抗光变、去噪、边缘、形态学 | 11–14 |
| 第五组 | 批量处理、旋转框、匹配定位 | 15–18 |
| 第六组 | 机器学习与神经网络 | 19–24 |
| 第七组 | 目标检测与项目实战 | 25–29 |
| 第八组 | 标定与执行，把视觉接到真机上 | 30–31 |

## 几个值得先看的章节

- **数据流总图**：讲清楚每一层输出什么，为什么按这个顺序调试
- **冗余与性能**：哪些步骤可以砍，每条都带实测数字
- **拿到一个新任务，按这 7 步走**：从读图到执行的固定流程
- **选工具速查**：要干什么，翻哪个模板
- **常见小问题**：先查这里，再问人

## 怎么用

抄代码三步：跟着敲一遍，故意改一个数字（阈值、尺寸、k）看结果怎么变，把有用的新代码补进字典。

改动之后把结果图存下来，方便以后对比。

## 维护约定

新模板从 32 号接着排，旧编号不动。课程文档里引用“模板 15”，永远指的是同一个东西。
